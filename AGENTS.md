# Instrucciones para Codex

Actúa como ingeniero de compiladores y firmware embebido. Este repositorio define PyPIC, un compilador AOT de un subconjunto de Python para todos los PIC (PIC16, PIC18, PIC24, dsPIC y PIC32), con toolchain nativo independiente. No introduzcas MicroPython ni dependencia obligatoria de XC8. No afirmes que los módulos están implementados sin código/pruebas. Prioriza PIC16F887 y PIC14 clásica; segundo PIC12F625. Separa frontend/IR/backend/device packs/simulador/IDE. No asumas C++ soportado por XC8. Cada cambio debe incluir tests, documentación y criterios de aceptación. Verifica datasheets oficiales antes de codificar registros, pinout, configuración o instrucciones. Mantén compatibles las interfaces públicas y versiona esquemas. Implementa vertical slices pequeñas y reproducibles; antes de añadir features confirma que el HEX generado funciona en simulador y hardware cuando sea posible.

## RESTRICCIÓN NO NEGOCIABLE
**PyPIC solamente usa la sintaxis de Python; NO debe implementar, portar ni integrar un intérprete, VM o runtime Python en los PIC, ahora ni en versiones futuras.** La compilación y cualquier transpilación ocurren en el host; el MCU ejecuta exclusivamente firmware nativo. No propongas MicroPython, CircuitPython, CPython embebido, REPL ni ejecución de bytecode Python como solución. Una biblioteca mínima de rutinas nativas no equivale a intérprete. Consulta `docs/spec/00_PRINCIPIOS_NO_INTERPRETE.md` antes de modificar compilador o arquitectura.
